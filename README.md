# Угадай число

Консольная игра на Python. Компьютер загадывает число от 1 до 100, нужно угадать за 7 попыток.

## Возможности

- Подсказки «Больше» или «Меньше» после каждой попытки
- Защита от ошибок: если ввести буквы или число вне диапазона — игра не вылетит
- После окончания игры можно сыграть снова
- Счётчик использованных попыток

## Как запустить

1. Убедись, что установлен Python 3.
2. Скачай файл `guess_the_number.py`
3. Запусти в терминале:
   ```bash
   python guess_the_number.py
